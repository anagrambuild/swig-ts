# Swig TS
_Swig Typescript_

This repository holds the goodies for interacting with Swig using typescript. 

### Run locally

Build the workspace locally by:

1. Installing the packages with:

```bash
bun install
```

2. Build the packages with:
```bash
bun build:packages
```

3. Build the swig program from source with:
```bash
bun update:program
```

4. Run our examples
```bash
cd examples/classic/transfer
```
```bash
bun <filename.ts>
```
